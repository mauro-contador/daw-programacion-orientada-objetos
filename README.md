# Programación Orientada a Objetos - DAW

Repositorio académico con ejercicios y prácticas realizadas durante el módulo de Programación de 1º de Desarrollo de Aplicaciones Web (DAW).

## Contenidos

En este repositorio se trabajan conceptos como:

- Programación orientada a objetos
- Abstracción
- Herencia y polimorfismo
- Excepciones
- Colecciones, genéricos y mapas
- Ficheros
- Conexión y acceso a datos
- Ejercicios y preparación de exámenes

## Tecnologías

- Java
- IntelliJ IDEA
- Git
- GitHub
